# Sample vault (fictional)

Every note in this folder is invented for the demo and the evaluation. "Quillmoor Labs" and its product
"Tidewell" do not exist; any resemblance to a real company, product or person is accidental.

The notes carry provenance frontmatter (`type`, `status`, `tier`, `reliability`, `generated_by`, `verified`,
`volatility`) and include deliberate conflicts: an old runbook next to its replacement, a chat summary that
contradicts the reference page, two price lists that are both still marked active, and a model-written research
note that disagrees with the final decision record.
