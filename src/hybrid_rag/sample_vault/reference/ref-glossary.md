# Engineering glossary

## Terms

Canary: a small share of real traffic sent to a new version before everyone gets it, so a bad release
hurts few users. Blue-green: two identical production environments; one serves traffic while the other
receives the next release. RPO: recovery point objective, the most data loss we accept, measured in time.
RTO: recovery time objective, the longest outage we accept before service is restored. Burst: requests
allowed above the steady rate for a short moment.
