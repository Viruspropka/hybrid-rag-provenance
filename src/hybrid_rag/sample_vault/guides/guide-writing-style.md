# Writing style for docs and runbooks

## Rules

Write the action first, then the reason. Use short sentences and plain words. Every runbook step must be a
command or a check that someone half awake at 3 in the morning can follow. Date every page with a verified
field in the frontmatter, and mark replaced pages as superseded instead of deleting them.
