# New engineer laptop setup

## First day

Install the package manager and the dev container runtime, then clone the monorepo and run the bootstrap
script. It installs the language toolchains in the versions pinned by the repository.

## Access

Register your hardware security key, then request VPN access and production read access through the access
portal. SSH keys are created on the hardware key and never copied between machines.
